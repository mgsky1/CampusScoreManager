# 接口文档

## 用户控制

**用户登录**

URL：/api/v1/user/login

请求方式：POST

入参

```json
{
  "username": "用户名",
  "password": "密码"
}
```

出参

```json
{
  "code": 200, // 标记登录是否成功
  "msg": "用户名或密码错误", // 错误提示
  "data": {
    "token": "xxxx", // 登录token
    "redirect": "TEACHER" // 如果登录成功，用来标记要跳转到学生端还是教师端
  }
}
```

备注

- code含义：
  - 201: 用户名或密码错误

**用户登出**

URL：/api/v1/user/logout

请求方式：POST

入参：无

出参：

```json
{
  "code": 200 // 标记这次请求是否成功
  "data": "成功"
}
```

## 学生端

**获取学生信息**

URL：/api/v1/student/get

请求方式：POST

入参：

```json
{
  "id": 1 // 学生id
}
```

出参

```json
{
  "realName": "黄xx", // 真实姓名
  "loginName": "hh", // 登录名
  "grade": 3, // 年级
  "subject": "计算机科学与技术", // 专业（写死）
  "tel": "13911111111", // 电话
  "address": "SMU" // 地址
}
```

**修改学生信息**

URL：/api/v1/student/update

请求方式：POST

入参

```json
{
  "loginName": "hh", // 登录名
  "grade": 4, // 年级
  "tel": "13911111112", // 电话
  "address": "SMU2" // 地址
}
```

出参

```json
{
  "code": 200,
  "msg": "成功"
}
```
