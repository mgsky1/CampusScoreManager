# 接口文档

## 用户控制

**用户登录**

URL：/api/v1/user/login

请求方式：POST

入参

```json
{
  "username": "用户名",
  "password": "密码"
}
```

出参

```json
{
  "code": 200, // 标记登录是否成功
  "msg": "用户名或密码错误", // 错误提示
  "data": {
    "token": "xxxx", // 登录token
    "redirect": "TEACHER" // 如果登录成功，用来标记要跳转到学生端还是教师端
  }
}
```

备注

- code含义：
  - 201: 用户名或密码错误

**用户登出**

URL：/api/v1/user/logout

请求方式：POST

入参：无

出参：

```json
{
  "code": 200 // 标记这次请求是否成功
  "data": "成功"
}
```
